# Security reports

Please use the repository's **Security → Report a vulnerability** option for sensitive reports. If it is unavailable, open an issue asking for a private contact without disclosing the vulnerability or affected data.

Include the affected file or version, a minimal reproduction with invented data, and the impact. Do not probe another person's installation. This community project has no guaranteed response time.

Deployment operators are responsible for their own infrastructure, provider keys, authentication configuration and data retention. Demo data is not evidence that an installation is safe for client records.
