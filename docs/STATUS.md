# What this edition contains

This is a customizable foundation, released as it stands.

- **Web:** a complete visual demo with sample sessions, checkpoints, planning and coaching screens. Supabase adapters are included; web coaching and some adapters need application-specific integration.
- **Mobile:** training and checkpoint screens, local history, and a native iOS MediaPipe camera plugin. Android needs its own native pose integration. No App Store release is supplied.
- **Vision:** 33-landmark pose detection and geometric form analysis. Checkpoint scoring includes simulated results. These are not medical measurements or validated injury predictions.
- **ML:** extraction, labeling, training and export source. No trained custom correction model is bundled; the runtime correction hook is a stub.
- **Data:** Supabase SQL, access policies and an optional AI coaching function. The mobile local history is not automatically synchronized into the web workspace. Schedules are schema and product groundwork, not a delivered CRM or reminder service.

Connect and review the paths your practice needs before using real client data. There is no obligation to complete every part to use another part.
