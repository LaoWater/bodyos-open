# Start with the part you need

**I want to see it.** Run `node scripts/start-web.mjs` for a guided start, or the web commands in the root README and choose Try Demo. Sample scores and people illustrate the interface.

**I want it for my practice.** Follow [Customize](CUSTOMIZE.md). Begin with your name, colours and exercise copy. Keep sample data while you decide what you need.

**I develop software.** Read [Architecture](ARCHITECTURE.md), then the README in the folder you are changing. The web, mobile, ML and database have separate dependency sets; install only the one you need.

**I want camera analysis.** Read [the mobile guide](../apps/mobile/README.md). Native iOS work requires macOS, Xcode and a development build; Expo Go cannot load the custom camera plugin.

**I want to contribute.** Read [CONTRIBUTING](../CONTRIBUTING.md), open an issue with one clear change, then work in a branch. Documentation and usability contributions are welcome.
